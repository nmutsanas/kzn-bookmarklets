# KZN Bookmarklets – Seite

Automatisch gebaut, **nicht hier bearbeiten**: dieses Repository wird bei jedem
Deploy überschrieben. Quelle und Issues im (privaten) Repository `nmutsanas/kzn-tools`,
Verzeichnis `bookmarklets/`.

Neben `index.html` liegt pro Bookmarklet ein Verzeichnis mit den gebauten Varianten
(`intranet-noten-importierer/`, `moodle-switch/`, `moodle-noten/`, `moodle-manuelle-bewertung/`) – die Seite verlinkt sie,
und sie sind das Einzige, worüber die Userscript- und Tampermonkey-Varianten zu
bekommen sind: im Quellrepository sind sie nicht eingecheckt.

Seite: <https://nmutsanas.github.io/kzn-bookmarklets/>
